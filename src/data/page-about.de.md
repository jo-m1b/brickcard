# Über

> LEGO® ist eine Marke der LEGO Group. Diese App ist ein persönliches Projekt und weder mit der LEGO Group verbunden noch von ihr gesponsert.

Brickcard ist eine kleine App, mit der du hübsche Karten im Spielkartenformat für deine LEGO® Steine erstellst und druckst. Sie beschreiben deine LEGO® Sets (Nummer, Foto, Titel, Thema, Jahr und Teileanzahl).

Erstelle Karten, drucke sie, laminiere sie und stecke sie mit einem Set ohne Schachtel in eine Klarsichthülle. Meine Kinder lieben sie — und so packt man nicht aus Versehen das falsche Set aus :P

## Funktionen

- **Karten erstellen und bearbeiten**: Nummer, Foto, Titel, Thema, Jahr, Teileanzahl…
- **Druckbereit**: A4-Raster von 1×1 bis 10×10, Vorder- und Rückseite für Duplexdruck ausgerichtet
- **Themen**: Standardthemen (Name, Logo, Farbe) + deine eigenen Themen
- **Automatisches Speichern**: alles liegt im Browser (IndexedDB)
- **Export / Import**: `.brickcard`-Dateien (Karten + eigene Themen) zum Sichern und Teilen deiner Sammlung
- **Durchsuchbare Liste**: finde schnell eine Karte und wähle sie zum Drucken aus
- **Installierbar**: funktioniert als PWA auf Handy oder Desktop
